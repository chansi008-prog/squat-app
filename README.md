# 하루 스쿼트

캐릭터·음악·목소리와 함께 하는 스쿼트 PWA. 로그인·서버 없음, 기록은 각자 폰(localStorage)에만 저장.

- `index.html` / `style.css` / `app.js`: 홈 (오늘 횟수, 운동 설정, 기록 달력·연속일)
- `squat.js`: 운동 화면 (건강 Reset 앱의 '스쿼트 같이 하기'를 가져와 횟수 10/15/20 · 세트 1~5 · 휴식 10/20/30초 선택)
- `sw.js`: 오프라인 캐시. 파일을 바꾸면 `VERSION`과 app.js의 `VERSION`을 함께 올린다.
